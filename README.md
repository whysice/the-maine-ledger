# Maine Ledger

An independent weekly brief on Maine's county jails, state prisons and criminal courts. Live at https://maineledger.netlify.app/.

The site is static HTML, CSS and JavaScript. There is no framework and no `package.json`. Facility, bill, topic and issue pages, and the home page, are generated from `data/ledger.json` and `src/issues/`. The other pages are hand-written.

To publish a new issue, follow the steps in the note at the top of `data/ledger.json`.

## Layout

- `data/ledger.json` holds the source data: facilities, bills, topics, items and issues.
- `src/issues/` holds the issue sources. They are built into `/issue/N` and the home page and are not served directly.
- `facility/`, `bill/`, `topic/` and `issue/` are generated by `scripts/build.mjs`. Edit the data file, not these pages.
- `scripts/build.mjs` checks the data and writes the generated pages.
- `scripts/version.mjs` writes `version.json` with the date of the deployed commit.
- `templates/email.html` is the email template. It is kept in the repository and not served.
- `sw.js` is the service worker. Raise `CACHE` whenever you change a file in its `PRECACHE` list.
- `docs/` holds the published design review.

## Run it locally

Needs Node.js. Version 22 is what this README was checked against.

1. Rebuild the generated pages:

   ```bash
   node scripts/build.mjs
   ```

   The build fails on a bad id or tag in `data/ledger.json`. Warnings are printed but do not stop it.

2. Serve the repository root with any static server, for example:

   ```bash
   python3 -m http.server 8000
   ```

   Then open http://localhost:8000/. Site search only works after building the Pagefind index (`npx -y pagefind@1.1.1 --site .`), which writes `pagefind/`. That folder is git-ignored.

## Checks

There is no test suite. Before committing a change to the data or the build, run:

```bash
node scripts/build.mjs --check
```

It fails if any committed generated page is out of date.

## Deploy

Netlify deploys `main`, with settings in `netlify.toml`. The build command runs `scripts/build.mjs`, then Pagefind, then `scripts/version.mjs`, and publishes the repository root. Every pull request gets a deploy preview at `deploy-preview-<number>--maineledger.netlify.app`.

Because the root is published, any new top-level file becomes a public page. Add a 404 redirect in `netlify.toml` for anything that is not meant for readers.
